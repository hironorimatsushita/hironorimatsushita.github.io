日本語

gcal-weekly は開発者本人のみが利用する個人用ツールです。Google Calendar API(読み取り専用スコープ)を用いて、開発者自身のカレンダー予定を取得し、ローカル環境での週次計画作成に利用します。取得したデータは開発者のローカル環境にのみ保存され、第三者への提供・共有・販売は一切行いません。第三者のデータを収集することもありません。認証情報はローカルに保管され、外部サーバーへ送信されません。

English

gcal-weekly is a personal, single-user tool used only by its developer. It uses the Google Calendar API (read-only scope) to fetch the developer's own calendar events for local weekly planning. Retrieved data is stored only on the developer's local machine and is never shared with, provided to, or sold to any third party. No third-party data is collected. Credentials are stored locally and are not transmitted to any external server.

gcal-weekly's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
